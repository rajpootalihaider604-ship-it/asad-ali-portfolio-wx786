ASAD ALI PORTFOLIO WEBSITE
==========================

Files:
- index.html  Main portfolio page
- style.css   Responsive dark/purple-blue design
- script.js   Mobile menu, active navigation and contact email form
- profile.png Your uploaded portrait image

HOW TO PREVIEW
1. Extract this ZIP folder.
2. Open index.html in Chrome or another browser.

HOW TO ADD YOUR OWN PHOTO
Your uploaded portrait is already saved as profile.png and linked in index.html. To change it later, replace profile.png with another image using the same filename.

HOW TO DEPLOY ON VERCEL
1. Sign in to https://vercel.com/
2. Create a new project and import a GitHub repository containing these files,
   OR use Vercel's supported deployment workflow for a static HTML project.
3. No build command is needed; the root directory contains index.html.
4. Deploy and open the generated URL.

IMPORTANT
- The contact form opens the visitor's default email app. It does not submit to a server.
- Update the email and WhatsApp number in index.html and script.js if your contact
  details change.
- The design is inspired by the overall layout/style of the example portfolio,
  but the text and portfolio identity are customized for Asad Ali.
